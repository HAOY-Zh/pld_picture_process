# CT Studio 演示视频流程与配套旁白

适用：2026-10-27 当前网页版本，入口 `http://127.0.0.1:8099/`。建议成片约 **5 分钟**，另保留未剪辑的实际运算录像。

## 一条主线

**一组胸部 CT → 可选的低剂量增强 → 肺区分割与三维清理 → 肺结节可疑候选定位 → ROI 局部定量 → 查看实际耗时与导出记录。**

基础处理放在导入后的短演示中，用于调窗观察和二值图处理。视频重点是同一份影像及其空间坐标在各工作区之间连续流转，以及 FPGA 实际承担的计算。

建议片名：**《CT Studio：基于 PYNQ-Z2 的 CT 增强与肺部智能分析系统》**。

## 录制前准备

1. 板子开机、接好网线，等待全部启动自检通过；网页左下角确认 FPGA 已连接。录制期间不要同时运行另一个控制 FPGA 的 Notebook。
2. 选择一组已经实际检查过、展示效果清楚的公开匿名 CT。优先用同一病例串起全过程，记录数据集来源。路径尽量简短，避免录入个人信息。
3. 提前完成一次该病例的全流程，选好一张有代表性的增强对比切片、一个候选编号和对应 ROI。增强后分析时，确认顶部“影像来源”确实切到增强 CT。
4. 另录一遍实际任务启动、进度和完成画面。整例增强、分割和候选检测需要等待，剪辑时压缩等待过程，明确标注“等待过程已剪辑”或实际倍速。
5. 当前基础处理和 LDCT 只有 FPGA 执行。ROI 仍有独立执行位置选项，录制硬件定量时需主动选 **FPGA ROI · 实际硬件**。
6. 浏览器放大到能看清参数和结果的比例，关闭开发工具及无关窗口。鼠标每次点击后停顿约一秒，字幕不要挡住图像和耗时。

> 不要为了缩短等待而只加载少数切片，再把结果称为整肺三维或整例候选检测。局部输入应明确叫“局部片段”。

## 分镜与操作

| 时间 | 画面与实际操作 | 需要让观众看清的内容 |
|---|---|---|
| 0:00–0:20 | 板子实物、网线与电脑，切入系统全景 | 使用 PYNQ-Z2，板子与上位机共同组成系统 |
| 0:20–0:45 | 输入 CT 路径，检查并加载单一序列，滚动几张切片 | 同一组影像、切片数、空间信息、已连接状态 |
| 0:45–1:15 | 基础处理：肺窗/软组织窗各应用一次；HU 阈值后再做一次开或闭运算 | 左侧原图、右侧结果；形态学使用已生成的二值图 |
| 1:15–1:55 | LDCT：选 Tiny CNN，预览当前切片；展示整例增强的真实启动与完成片段 | 原图与增强图使用相同显示窗；显示实际耗时 |
| 1:55–2:45 | 选择分析来源；点击“整例分割 · 自动三维清理”；完成后滚动 MPR、旋转三维 | 清理后的二维掩膜、三个切面、肺三维以及体积 |
| 2:45–3:35 | 启动整例结节候选检测；完成后点击一个候选，再选另一个 | 候选列表、局部放大、切片定位和三维标记同步变化 |
| 3:35–4:15 | 点击“带此框进入 ROI 定量分析”，选择 FPGA ROI，分析当前层；有时间再展示连续层段 | 自动带框、局部放大、筛选像素、面积、HU 与范围体积 |
| 4:15–4:45 | 打开性能记录，指向本次推理/往返/点击至显示耗时，再导出会话 | 实际回执、计时范围、输入来源与结果可追溯 |
| 4:45–5:00 | 回到分割与三维全景，片尾 | 系统主线与 FPGA 贡献，工程演示声明 |

如比赛限时 3 分钟，压缩基础处理到 15 秒、ROI 到 20 秒，保留增强、分割、候选联动和性能证据。

## 可直接朗读的旁白

### 1. 开场

“这是我们基于 PYNQ-Z2 开发的 CT Studio 医学影像处理系统。我们围绕一组胸部 CT，完成影像增强、肺区分割、三维观察和可疑结节定位，并将候选区域带入局部定量分析。电脑负责交互和结果组织，FPGA 承担核心图像处理与模型推理。”

字幕：**同一病例，贯通增强、分割、候选定位与定量分析。**

### 2. 导入与基础处理

“首先导入公开匿名 CT。系统按空间位置组织切片，保留原始 HU 和毫米坐标。这里可以通过窗宽窗位观察不同组织，也可以先生成 HU 阈值二值图，再对这个二值结果执行形态学处理。这些基础运算由 FPGA 执行，处理结果独立保存。”

字幕：**FPGA 基础处理：调窗、HU 阈值、腐蚀、膨胀、开闭运算。**

操作提示：不要只改肺窗下拉框就立刻说“处理完成”，需要点“应用处理”，让右侧出现新结果。

### 3. LDCT 增强

“针对低剂量 CT 的噪声问题，我们部署了轻量 CNN 增强模块。左边是原始影像，右边是 FPGA 计算得到的增强结果，两图使用相同显示窗进行比较。整组增强完成后，可以直接选择增强影像，继续进行后续分析，原始影像也会保留。”

字幕：**轻量 CNN · 100 MHz FPGA 增强 · 原始 HU 与结果分别保存。**

若此处跳过等待，叠加字幕：**本次实际运算，等待过程已剪辑；耗时以界面记录为准。**

### 4. 肺分割、三维清理与 MPR

“肺区分割采用轻量 U-Net，通过 INT8 定点计算在 FPGA 上推理。整例计算完成后，系统自动执行三维清理，并同步更新切片叠加和三维结果。现在可以从轴位、冠状位、矢状位观察同一位置，也可以旋转肺部三维结构，查看分割范围与体积。”

字幕：**INT8 U-Net → 三维清理 → MPR 与三维同步展示。**

讲解时补一句即可：**“三维清理与网格生成在电脑完成。”** 不需要在每个镜头重复介绍软硬件分工。

### 5. 结节可疑候选与联动

“在已有肺区分割的基础上，系统使用相邻多层输入的 2.5D CNN 搜索可疑结节，并结合跨层评分形成三维候选。肺分割与结节检测复用同一套 FPGA 计算引擎，通过不同权重和调度完成两个任务。点击候选后，切片位置、局部图和三维标记同步定位，便于查看它在整个肺部的位置。”

字幕：**肺区约束 · 2.5D CNN · 三维候选定位 · 共享 FPGA 计算引擎。**

默认使用 **0.7656 严格档**。若要展示阈值功能，可补录：选择 0.8738 后点“按所选档位重新筛选”，再切回原档。旁白用：

“已有候选可以按不同阈值重新筛选，无需重复运行 CNN。提高阈值会减少候选，同时也可能增加漏检。”

这一小段可不放入主片，避免主线被参数对照打断。

### 6. ROI 定量

“候选区域可以直接带入 ROI 工作区，无需重新手动画框。这里选用 FPGA ROI，对选定区域做筛选、计数和 HU 统计，并根据影像空间信息得到面积或连续层段的体积。结果同时记录病例来源、筛选条件和执行耗时，可以继续导出。”

字幕：**候选自动带框 → FPGA ROI 统计 → 面积 / HU / 范围体积。**

### 7. 性能与收尾

“系统同时记录 FPGA 推理、通信往返和网页显示等不同范围的耗时。我们的优化包括定点推理、计算引擎复用，以及采样、数据搬运和保存流程优化。最后可以导出本次会话，保留影像来源和执行记录。这个系统将影像处理、智能分析和交互观察组织成一条可重复演示的流程。”

片尾字幕：**仅用于工程教学与算法演示，不作为临床诊断依据。**

## 性能画面怎么写

主片优先展示本次界面产生的真实耗时。需要额外放一张优化对照卡时，可用此前同一例351层的已验收整例结果：

| 功能 | 优化前 | 已验收版本 | 耗时减少 |
|---|---:|---:|---:|
| LDCT 增强 | 201.691 s | 183.628 s | 8.96% |
| 肺分割与重建 | 199.903 s | 195.090 s | 2.41% |
| 结节候选检测 | 80.241 s | 72.727 s | 9.36% |

卡片脚注必须保留：**历史单例、旧版与优化版各一次完整对照；含准备、通信、保存与对应后处理，不含首次读入、启动自检、预热及浏览器绘制。当前严格阈值另作选择，候选数量可能变化。**

这些数字是前后优化对照，不是当前 FPGA 相对电脑的加速比。若展示 ARM/FPGA 对照，使用已核验的同模型、同量化、同输入计时，明确是网络阶段还是完整流程。

## 录制时统一口径

- 候选框叫“可疑候选区域”，分数不是恶性概率；包围框及 ROI 范围体积不是精确结节分割体积。
- 无专家标注的演示病例不报 Dice，也不从画面估计检出率。历史 FP32 测试指标不能直接说成当前 INT8、增强后输入的新测试结果。
- 没有配对正常剂量参考时，只展示增强前后实际图像，不虚构 PSNR、SSIM 或“增强必然提高分割精度”的结论。若输入来自 LUNA16，只说明公开胸部 CT 上的增强演示，不称为已验证的低剂量配对试验。
- 当前不是所有模块放在一个 bit：基础、LDCT、共享 CNN、ROI 等仍按任务调度切换；肺分割与结节检测已经共享计算引擎。统一 bit 尚未开始，视频不要写“全流程零 bit 切换”。
- 三维清理、三维网格和网页显示由电脑完成，不能将完整系统都称为纯 FPGA 实现。
- 当前没有新增实测功耗数据，片中不写未经测量的瓦数或节能百分比。
- 若使用事先完成的结果，注明“本例已完成结果回放”；如展示实际运行过程，保留真实启动和完成片段，等待部分按标注剪辑。

## 配视频发布的简短说明

本视频演示 CT Studio 在 PYNQ-Z2 上的医学影像处理流程：公开 CT 导入、FPGA 基础处理、轻量 CNN 增强、INT8 U-Net 肺区分割、三维清理与 MPR、2.5D CNN 结节可疑候选定位，以及候选到 ROI 的联动定量。肺分割与结节检测复用同一套 FPGA 计算引擎，系统记录实际执行耗时与结果来源。整例运算的等待过程已按视频字幕剪辑。作品仅用于工程教学与算法演示，不作为临床诊断依据。
