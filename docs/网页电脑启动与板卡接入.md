# 网页电脑启动与板卡接入

更新日期：2026-10-18。统一入口为python/ct_workspace_web.py，网页默认仅监听本机127.0.0.1:8090。

## 1. 没有开发板也能启动

建议Python 3.11，在项目根目录新建环境，不复制原电脑的.venv-lung。

Windows PowerShell：

```powershell
py -3.11 -m venv .venv-web
.\.venv-web\Scripts\python.exe -m pip install -r python/requirements-web.txt
.\.venv-web\Scripts\python.exe python/ct_workspace_web.py --desktop
```

macOS/Linux使用对应环境入口：

```bash
python3.11 -m venv .venv-web
.venv-web/bin/python -m pip install -r python/requirements-web.txt
.venv-web/bin/python python/ct_workspace_web.py --desktop
```

打开http://127.0.0.1:8090/。电脑模式不读取data里的旧模型/配置，不导入PyTorch，不连接FPGA；显示明确的“电脑浏览模式”和“电脑参考预览”。所有文件路径都指向运行该网页后端的这台电脑。

可使用的功能：DICOM/NIfTI/NPZ输入、原始HU与空间信息读取、切片/MPR浏览、窗宽窗位、直方图/伪彩、阈值及二值形态学参考、处理记录与导出。形态学需先保存当前切片的阈值结果。

真实神经分割、预测掩膜三维、分割Dice和真实硬件指标需实际板端输出；电脑模式不会假造这些结果，也不包含离线神经分割替代。

## 2. 合成教学样例

```powershell
.\.venv-web\Scripts\python.exe python/create_demo_ct.py
```

程序在data/demo/synthetic_ct.npz生成带HU及毫米空间信息的人工几何体，输出已存在时拒绝覆盖。样例不含患者数据、不含专家标签。

把输出的绝对路径粘贴到网页，勾选HU/mm确认，取消“加载专家标注”，点击加载。可先测试窗宽窗位，再做阈值和开闭运算；在分割工作区查看三个方向的原始切面。数据虽为HU数值形式，仍是合成工程样例，不作为真实患者或医学精度证据。

端口8090被占用时可用--port 8092，随后打开对应地址。按Ctrl+C停止自己启动的网页后端，不需要修改防火墙开放远程访问。

## 3. 接入真实FPGA

集成负责人取得匹配的主机/板端运行包后：

1. 按运行包说明在板端启动唯一服务，取得对应模型契约、bit/HWH、版本清单和当前部署自己的私有令牌。
2. 在电脑环境安装兼容的PyTorch 2.8前后处理依赖。网页本身不在电脑运行神经网络，但真实输入量化和输出恢复沿用冻结Torch规则。
3. 使用显式配置启动：

```powershell
.\.venv-web\Scripts\python.exe python/ct_workspace_web.py --config data/ct_platform_fast_20261017_v2/host_config.json
```

该路径只是现有包的示例，必须先实际取得资产并按自己的网络与凭据配置。程序校验模型和板端身份，不能把剪枝实验包直接冒充当前网页模型。

若本机已有原默认data/ct_platform_20261017_v2/host_config.json，直接运行脚本仍沿用该硬件配置；显式--desktop才强制电脑模式。指定了--config却缺文件/模型不匹配时会启动失败，不会静默切换到电脑执行。

所有运行包、CT和私有令牌仍不纳入普通Git源码；原包清单绑定文件哈希，更换凭据应生成新的交付副本并更新相应清单，不改写旧验收资产。
