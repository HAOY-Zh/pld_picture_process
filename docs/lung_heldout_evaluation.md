# 冻结模型后的独立肺分割测试

这是电脑 CPU/GPU 上与人工标注的精度评价，不是 PL 推理，也不是临床验证。
仅用于工程教学与算法演示，不作为临床诊断依据。

## 与之前六病例评价的区别

原来的 `lung_unet.py evaluate` 默认评价六个开发验证病例，用于模型开发。
它们不是独立测试集；18 个训练病例和 6 个验证病例的划分保持不变。

新入口 `python/lung_heldout.py` 固定已选择的 2D 模型，不训练、不根据测试分数
选择 checkpoint、不提供逐测试病例选择或阈值调节选项。此次选择的是
`early_stop_run/best.pt`，即第 12 轮的原 2D 模型，概率阈值固定为 0.5。

下载审计包含 24 个官方测试病例目录：先前有 17 个 CT/标注齐全候选，另外
7 个没有 CT。程序重新尝试全部 24 个，不因模型分数差而排除病例。
若仍有缺失，只能称为可用测试子集，不能称为官方 24 病例完整成绩。

## 运行

在项目根目录的电脑 PowerShell 执行，不在板卡 Jupyter 执行：

```powershell
.\.venv-lung\Scripts\python.exe python/lung_heldout.py --dataset data/lung_learning_20261009/dataset.json --checkpoint data/lung_training_20261011/early_stop_run/best.pt --audit data/lung_validation_20261009/download_audit/audit.json --input-root D:/CT2/lctsc --outdir data/lung_training_20261011/heldout_2d_evaluation --device cuda
```

输出目录必须为空；复跑时指定新目录，不能覆盖这次结果或协议。
源 CT、RTSTRUCT、训练数据、历史实验和模型权重不会被修改。

## 防止泄漏和指标误读

- 读取测试 CT/标注前写入 `protocol.json`，冻结权重 SHA256、开发数据指纹、
  代码 SHA256、预处理、阈值、全部候选清单及统计口径。
- 检查患者 ID 哈希、Frame UID、Series UID、CT SOP UID：不能与开发病例
  或其他已接受测试病例重叠。患者身份不明确时不将其当成独立样本。
- CT 物理顺序、层间距、方向、形状和人工标注的 SOP/Frame 关联均需通过检查。
- 输入沿用 HU 截断 [-1000,400]、线性缩至 256、归一化及 float16 缓存；
  预测概率双线性恢复原始尺寸后以 0.5 二值化。人工左右肺轮廓的并集
  保持原始尺寸，不缩放参考标签来迁就模型。
- 保留全部 CT 层，包括人工肺掩膜为空的层。整病例 Dice 先算各病例再平均；
  同时报告 IoU、精确率、召回率、小/中/大肺区逐切片 Dice、空层误分。
  无定义的指标为 null，不把双空掩膜计作完美 Dice。
- 缺文件、几何异常、身份重叠等有明确失败记录；推理/统计发生错误则中止
  并保留未完成状态，不能悄悄删去失败病例。低 Dice 本身不构成排除理由。
- 同时输出固定规则基线作参考，但两个计时范围不同，不能据此宣称加速倍数、
  FPGA FPS 或临床性能。没有同时测试其他公开网络，不构成同条件 SOTA 排名。

## 产物

输出目录 `data/lung_training_20261011/heldout_2d_evaluation/`：

- `protocol.json`：测试前冻结的协议和权重/代码哈希。
- `test_dataset.json`：尝试范围、实际可用病例、数据问题及独立性检查。
- `evaluation.json`：最终状态、覆盖率、汇总、逐病例/逐切片统计。
- `case_metrics.csv`：便于队友打开查看的逐病例表。
- `cache/<病例>/`：归一化输入、原始尺寸人工并集及元数据。
- `<病例>/prediction_native.npy`：0/255 模型输出。
- `<病例>/comparison_slice_*.png`：最大肺面积层、最差非空层、最严重空层误分
  （若有），不是只展示最好的层。青色=人工边界，黄色=规则基线，绿色=模型；
  误差图红色=多分、蓝色=漏分、灰色=正确选中的肺。

`data/` 被 Git 忽略；不会自动向 GitHub 上传患者数据、权重或图片。

查看测试分数后若继续针对这些病例改进算法，它们就成为开发反馈，不能
再把同一批成绩称为新的盲测。后续需要另一个未参与调参的独立集合。
