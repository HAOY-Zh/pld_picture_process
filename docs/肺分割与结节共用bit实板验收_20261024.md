# 肺分割与结节共用 bit：2026-10-24 实板回传验收

回传目录 `data/lung_nodule_shared_01` 已通过独立验收。一次加载同一个 100 MHz bit，随后在原始 U-Net、剪枝 U-Net 与结节 CNN 之间交替执行，没有重新配置 FPGA。

## 正确性

- 共 22 次模型调用、342 个节点数组，与各自冻结的 INT8 参考逐值一致；U-Net 的阈值掩膜也一致。
- 822 项其他模型驻留缓冲区哈希检查通过，没有发现相互覆盖。
- 全过程 ARM 650 MHz、PL 100 MHz；每帧缓冲区分配与权重重新打包均为零。每层执行仍加载对应模型权重，不能理解为模型切换没有权重传输。
- 两套 U-Net 的模型、参数、输入和参考文件与原独立包 SHA-256 一致。结节也沿用冻结模型。本轮没有训练、量化或阈值变更。

因此，本轮验证输入没有因共用 bit 引入数值差异。该结论不等于重新完成全数据集精度测试，也不等于已经完成网页整病例联调。

## 同一 bit 内切换是否变慢

下表的“初始”与“交替”均使用本轮同一个新版 bit；初始每个输入只测一次，主要用于正确性基线，并非独立版本的充分预热测速。

| 模型及单位 | 初始网络调用 | 交替后的网络调用均值 | 初始硬件活动时间 | 交替后硬件活动均值 |
|---|---:|---:|---:|---:|
| 原始 U-Net，一张 256×256 输入 | 437.090 ms | 431.566 ms（4 次） | 348.481 ms | 348.465 ms |
| 剪枝 U-Net，一张 256×256 输入 | 394.423 ms | 395.372 ms（4 次） | 322.999 ms | 322.996 ms |
| 结节 CNN，一个 128×128 patch 的五层上下文 | 51.067 ms（4 个输入） | 53.410 ms（8 次） | 13.703 ms | 13.703 ms |

硬件活动时间由每条命令的实际周期计数折算，切换前后均值变化均小于 0.005%。没有发现共享引擎导致计算周期增长。网络调用还包含输入打包与同步、寄存器配置、权重加载、等待、保护检查和输出整理；额外的节点快照与文件写入在计时之外。

结节网络调用交替后平均增加约 2.344 ms（4.59%），但硬件活动时间未相应增加。最后一次调用为 70.534 ms，其中输入同步/打包项为 31.794 ms，其余交替调用在 48.366–54.287 ms。当前短测试不足以把该波动归因为切换开销，也不能声称软件调用完全零开销。共享所有者在网络调用外的锁和检查等包装平均约 0.7 ms。

## 与历史 U-Net 独立版本比较

| 模型 | 2026-10-17 旧版 PL 网络调用 | 本轮新版共享 PL 网络调用 | 时延减少 |
|---|---:|---:|---:|
| 原始 U-Net | 552.647 ms | 431.566 ms | 21.91% |
| 剪枝 U-Net | 492.401 ms | 395.372 ms | 19.71% |

历史为 3 次预热、20 次正式测量，本轮为交替正确性验收中的少量样本。输入、权重和量化参考相同，但 bit 不同：历史使用旧 exact-LUT 实现，本轮沿用已验收的像素流水重叠新版 RTL。历史原始/剪枝模型硬件活动约 468.499/420.635 ms，本轮为 348.465/322.996 ms，说明新版硬件也使 U-Net 受益。这些数字是跨批次观察，不能全部归因于共用 bit，也不能作为同轮严格消融的最终性能数据。

共用 bit 的直接收益是复用同一套电路，并取消分割与结节模型之间的重新烧录。此次没有给出旧流程烧录时间的对照，因而不编造取消烧录所节省的毫秒数。

## 结节计时单位

本轮的 53.410 ms 是 **128×128 patch 对应网络的调用耗时**，输入已经变成 45×64×64 编码，不含 CT 五层在线采样、检测结果解码和整层候选合并。

此前约 **597.179 ms/检测平面** 是完整 448 画布路径，包含在线采样、网络和候选处理。两者不能直接比较为提速，也不能据此说整层检测降到了 53 ms。本轮没有重新测完整画布或整病例耗时。

## 资源与证据

沿用相同 bit，物理资源仍为 17,865 LUT、20,063 FF、80 DSP、31.5 BRAM tile。三套模型验证工作区同时常驻 CMA 共 15,860,736 B，约 15.13 MiB；此数不是整病例总内存。基础处理、LDCT 尚未因此自动集成进这个 bit。
