# 二维人体范围输出约束

针对 S3-002 第 186 层把人体下方支撑物识别成肺的问题，加入 **CT-only 人体包围范围**，
约束二维肺预测的输出。不是重新训练人体分割网络，不修改原始小型 U-Net、输入图像或原生标注。
也不是先画三维再隐藏错误区域：约束后的二值掩膜先生成，后续定量统计和表面都来自该掩膜。

## 实际算法与边界

1. 在原生 HU 切片上取 `HU > -500` 的组织候选，物理半径 3 mm 闭运算。
2. 选择最大相连组织组件，在**临时人体检测**中填孔以覆盖低密度肺内部。
3. 包围范围外扩 20 mm，并扩为保守的方形框；它是肺分析用的主人体候选范围，
   **不是逐像素皮肤轮廓或完整人体组织分割**，分离的手臂等部位不保证在框内。
4. 只保留原肺预测位于此范围内的像素，不增加前景、不修补肺内孔、不根据专家标签调整框。
5. 无可靠组织、均匀或候选过小时保守放行全视野，不强制输出为空。
6. 需要三维清理时，必须在人体约束后**重新**执行原 5 mL/20 mm 规则，不能仅把旧三维结果裁掉。

顺序：`原 HU → 原全视野二维模型 → 原生 0.5 阈值 → 人体范围输出约束 → 可选三维连通域清理 → 表面/MPR/体积`。
模型的 HU 归一化、256 输入、float16 缓存约定、概率原生双线性恢复和 0.5 阈值不变。
窗位窗宽只改变显示，不能用显示灰度来估计该框。

复用了旧 `lung_body_crop.py` 的 **CT-only 检测函数**，没有调用该废案的裁剪、恢复、训练或权重。
旧废案改变了网络输入与重新训练，本次只限制输出，是不同的实验。

- 专家肺区 0 像素；原模型 5257 像素；旧三维清理仍有 5200 像素。

范围内仍可能误分，估计失败时会放行，不能承诺所有人体外预测都会被清除。
