# CT Studio 最终版（2026-10-26）

对比基线为已上传的集成分支 `codex/ct-studio-integrated-20261025`，提交 `8a2a855a695b6e33b87bc29e8c7f2ae6d78121a5`。最终版更新 GitHub `main`，不从带有 PS 迁移实验的本机工作目录整体合并。后续同学的下载、运行和修改步骤见 [同学交接说明](同学交接说明_20261026.md)。

## 相对基线的新增

| 改动 | 结果与范围 |
| --- | --- |
| Windows 桌面启动器 | 完整私有包解压后双击 exe，检查环境、连接板子、启动本机网页并打开浏览器；附中文故障提示、重新连接和日志入口 |
| 现有服务身份检查 | 核对原配套令牌、服务清单、共享 CNN 身份和运行资产；不匹配时停止启动，不自动换板端程序 |
| 基础 FPGA 任务取消重复对比 | 六种基础处理只取实际 FPGA 输出，不同时运行电脑参考或逐像素对比；保存真实硬件回执、输入/输出哈希及所选掩膜来源 |
| 私有软件包构建源码 | 维护者指定原已安装配对目录和便携环境，可从当前源码重建完整软件包；路径在副本中调整，原令牌不重新生成 |
| 回归检查及开发交接 | 检查 FPGA 路径没有电脑参考/故障回退，电脑独立功能仍可用；补充肺结节检测的后续开发入口 |

本次没有新的模型训练、LDCT 算法、FPGA bit/HWH 或结节算法升级。原电脑端功能、FPGA 功能和执行位置选择均保留。取消的仅是基础 FPGA 任务里的自动重复电脑计算与对比；开发测试中的数值断言仍保留。

## 原版已经具备、最终版继续保留的能力

- CT 导入、原始/增强 HU 来源管理；基础处理和原有电脑预后处理。
- 原轻量 CNN 的 FPGA LDCT、原 INT8 肺分割、MPR、三维重建。
- 共享 CNN 结节候选检测、列表与三维联动、自动/手动 ROI、跨层统计与局部 MIP。
- 结节最多 8 块批量传输、提前采样、状态缓存和安全取消。

LDCT 从 50 MHz 到 100 MHz 的已验证加速已在基线中：指定测试平均每层约 515.619 → 373.936 ms，减少约 27.5%。记录在 `handoff/ldct-slice-v1-20261017/evidence/clock_comparison/result.json`，不是这次新增。

结节批处理在既有实板病例验证中从 696.98 → 431.29 秒，减少 38.12%；输入块、FPGA 输出、候选和自动 ROI 一致。精简记录在 `evidence/ct_studio_integration_20261025/verification.json`，同样已上传。该记录证明工程加速与一致性，不代表肺结节检测准确率已经验收。

本次不纳入 PS 网页/预后处理迁移、沿迁移路线加入的内存重构、EDCNN 各实验、新采样硬件、双通路硬件，以及只有电脑微基准或仿真而没有实板资格的 tile 缓存方案。实验原件留在原本机目录，未从磁盘删除。

## 同学继续修改肺结节检测

| 位置 | 职责 |
| --- | --- |
| `python/nodule_workspace.py` | 检测任务状态、当前病例/增强来源绑定、取消与候选结果接入 |
| `python/nodule_detector.py` | `NoduleCaseProvider`；采样、批量调用、解码与候选汇总 |
| `python/nodule_vendor/` | 当前算法、采样缓存和计划；保留来源记录 |
| `python/ct_studio_shared_client.py`、`python/shared_patch_contract.py` | 共享 FPGA CNN 请求、返回校验及固定数值契约 |
| `python/lungseg/workspace/nodule*.js` 与 `nodule.css` | 检测操作、候选列表、三维联动 |
| `pynq/ct_studio_shared_service.py` | 现有板端共享 CNN 服务；协议或模型变化需与电脑端同步配对 |

上述检测源码与基线保持一致，便于同学直接比较和继续开发。只改候选排序、阈值或界面时，先沿用现有模型/硬件；改采样、量化、网络输出或协议时，要同步更新相应契约和身份清单并重新验证，不能继续沿用旧的实板一致性结论。

建议回归入口（需原依赖环境，HTTP 替身测试仅使用本机回环地址）：

```powershell
$env:PYTHONPATH='python;python/tests;pynq;pynq/roi_vendor'
python -B -X utf8 -m unittest test_basic_single_path test_ct_platform test_ct_platform_fast test_ct_workspace test_ct_studio_boot test_integration_release test_nodule_speed test_nodule_online test_ct_nodule_workspace test_ct_roi_workspace test_ct_studio_shared
python -B -X utf8 -m unittest test_ct_workspace_desktop

```

无模型电脑浏览测试单独运行，以检查启动过程没有导入 Torch；不和已加载 Torch 的推理测试放在同一个 Python 进程。
