# 全部加速组合：六组实板验收结果（2026-10-17 回传）

六组回传已通过未修改的独立验收入口。原模型与 `fisher_moderate` 使用相同 CT 切片、相同 exact-LUT bit、相同实际时钟，均完成 3 次预热和 20 次正式测量。当前网页默认模型未因本次验收而更换。

## 实测结果

| 模型 | ARM FP32 双线程 | ARM 精确 INT8 双线程 | PL 精确 INT8 |
| --- | ---: | ---: | ---: |
| 原模型 | 1606.275 ms | 911.127 ms | 552.647 ms |
| fisher_moderate | 1351.758 ms | 797.458 ms | 492.401 ms |
| 剪枝与恢复训练方案的时延减少 | 15.85% | 12.48% | **10.90%** |

新候选的 PL 每张节省 60.245 ms。原模型/新候选的 PL 中位数为 552.249/491.772 ms，20 次实测范围为 547.489–566.037 / 486.849–508.526 ms，变异系数为 0.64%/0.88%。CPU 的变异系数约 2.83%–4.77%，完整 120 次记录见下方 CSV；本轮各阶段顺序执行，未额外做交错顺序重复实验。

## 各项收益的口径

| 比较 | 同轮结果 | 解释 |
| --- | ---: | --- |
| 原模型 ARM INT8 / 原模型 PL INT8 | 1.649 倍 | 固定模型和整数契约的硬件加速 |
| 剪枝模型 ARM INT8 / 剪枝模型 PL INT8 | **1.620 倍** | 最终候选的同模型硬件加速 |
| 原模型 ARM FP32 / 原模型 ARM INT8 | 1.763 倍 | 各自优化原生内核下的量化路径比较 |
| 剪枝模型 ARM FP32 / 剪枝模型 ARM INT8 | 1.695 倍 | 剪枝模型的量化路径比较 |
| 原模型 ARM FP32 / 最终剪枝 PL INT8 | **3.262 倍** | 剪枝、数值格式及执行平台的综合收益 |

同模型 CPU/PL 比值从 1.649 降到 1.620，原因是 CPU INT8 的时延减少 12.48%，高于 PL 的 10.90%。不能用原大模型的 CPU 时间除以新模型的 PL 时间，写成同模型硬件加速比。FP32/INT8 比较也包含所用原生软件内核实现差异，不把全部收益仅归因于位宽。

两边均已启用权重预打包、常驻缓冲、C++ 批量 MMIO、HWC8 并行卷积、卷积缓存/响应直通、池化双行缓存、精确拼接查表和 100 MHz 时钟核验；新候选另外改变通道、恢复训练权重及量化校准。原模型历史 flow→LUT 等实现收益沿用各自独立实板证据，不把本次同时启用的功能重新解释为逐项独立消融。

## 为什么工作量减少 16.12%，实际减少 10.90%

| 计时项 | 原模型 | 新候选 | 减少 |
| --- | ---: | ---: | ---: |
| 卷积活动周期折算 | 403.627 ms | 357.490 ms | 46.137 ms |
| 张量活动周期折算 | 64.872 ms | 63.145 ms | 1.727 ms |
| 整网壁钟与上述活动计时之差 | 84.148 ms | 71.766 ms | 12.381 ms |
| 整网实测 | 552.647 ms | 492.401 ms | 60.245 ms |

16.12% 是 HWC8 填充后输入工作量的缩减，并不覆盖全部输出写回、算子、同步和调度。浅层卷积、输出头、部分拼接和池化形状保留，实测相应周期基本不变。壁钟余量不是单独测得的纯 CPU 开销，保留其定义，不把它全部归为某一种开销。

剪枝复用相同 bit：`54f54656e405eb4cee0ce073d476665110ee49ef6f200ccdaf6edc814a85cafc`。因此物理资源仍是 17268 LUT、18455 FF、80 DSP、31.5 BRAM；参数减少 32.58% 和块命令 51→44 不代表物理 DSP/BRAM 同比例减少。

## 输出与时钟验收

- 输入：`LCTSC-Train-S2-006` 的零基索引 72，同一份归一化单通道 256×256 CT；FP32 使用真实浮点权重，INT8 按各模型自己的冻结网格量化。
- 实际频率：ARM 650 MHz、PL 100 MHz，各阶段和每帧读回核验。
- 两模型各 21 个节点以及每帧 INT8 输出均通过检查，每份实际 head 的 65536 个编码与精确整数参考逐点一致。
- 两模型的实际 FP32 head 最大绝对误差分别为 0.00003433 / 0.00002670，满足原有容差。
- 各自的 FP32/INT8 单张输出网格有 14/23 像素符号差异；这些不是原生 Dice，更不是数据集精度。
- 计时覆盖常驻网络输入到输出；首次编译、模型准备、bit 加载、HU 预处理、原尺寸恢复、身体约束/三维清理、网络往返与显示分别统计，未计入本表。

这是单张切片重复测速及实际输出验收。27 例、5286 层精度来自 [冻结整数参考的全量确认](lung_pruning_refinement.md)，不写成 5286 层均已上板。测试病例此前已观察，精度确认也不称为新的独立盲测。
