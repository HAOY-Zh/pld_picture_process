### 凭据和原始数据

现有平台包包含platform_token.txt，部分清单还绑定其哈希。对外交接前应创建**新的交付副本**，生成该部署自己的私有凭据、更新对应配置/清单并自检；不能只删除令牌后继续使用旧清单，更不能覆盖已验收包。

包里的input/reference等自检样例可能来自真实CT。需要核对数据来源、许可与分发范围，不能因为文件是NPZ就当成无医学数据。发布前逐项审查；必要时另外提供合成自检包并重新验证，不改写历史实板证据。

### 构建复现

部分构建/打包脚本依赖data里的历史manifest、已验收包、RTL快照或ps_settings.tcl。忽略data后，这些前置条件不会随源码自动出现。

因此源码上传并不等于所有版本都可从空目录一键重建。交接时应附匹配的最小构建快照/配置及版本索引，或明确提供已构建运行包；不要把依赖检查关闭来绕过缺失文件。
