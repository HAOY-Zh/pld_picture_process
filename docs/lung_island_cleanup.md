# 三维孤立误分清理：冻结模型的开发验证

这一步不重新训练、不改变模型权重、不修改人工标注，也不访问 Test/COVID 数据。
过滤只读取**模型预测、ZYX 物理间距和固定规则**；人工标注仅在过滤决定之后读入评分。
它是电脑端 CPU 三维后处理，不是新的神经网络或 FPGA 实现；仅用于工程教学与算法演示。

## 固定主规则

- 26 邻接三维连通域，包含对角相连的体素，避免轻易打断逐层的肺尖/肺底。
- 保护体积不小于 `max(10 mL, 最大连通域体积 × 2%)` 的主体组件，主体数量不强制为两个。
- 最大连通域不足 50 mL 时，主体不可靠，**不执行清理**。
- 只有同时满足“非主体、体积 ≤5 mL、到主体最近距离 >20 mm”的小块才删除。
- 距离是按真实间距计算的最近体素中心欧氏距离，不是二维像素距离或固定层号。
- 不填孔、不平滑、不扩张/腐蚀、不修补与主体相连的错分，不根据人工标注决定删除对象。

5 mL/20 mm 主规则在读取验证结果前固定。1/3/5 mL ×10/20/30 mm 九组只作敏感性展示，
没有自动挑出最高 Dice 的参数。上述数值是工程候选规则，不是临床边界标准。

## 六个原验证病例结果

模型仍是 `early_stop_run/best.pt`，原始 epoch 12、单切片小型 2D U-Net。
18 个训练病例/6 个验证病例划分和原生 512×512 标注未变。
结果是反复使用过的开发验证集成绩，不是独立盲测或泛化保证。

主规则共删除 34 个组件、6444 个 FP 体素（总 FP 减少约 2.36%），相对原始预测没有删除
与专家标注重合的体素；六例 Dice 均未下降。平均 Dice 增加 **0.0363 个百分点**，不是显著的大幅提升。
主要改善是远离主体的孤岛，没有解决肺主体边界、近邻假阳性或模型漏分。

有一张专家非空切片的原始预测只有错误前景，清理后变空：没有删除 TP，原始与清理后
这张切片 Dice 都为 0。报告 `lost_positive_slices=1` 表示该情况，**不是删除了真肺区**。

“只保留最大两个 26 邻接组件”对照平均 Dice 更高（0.9672942942），但误删 943 个真肺区体素，
小肺区平均 Dice 下降，所以不采用。10 mm 的候选规则也误删 127 个真肺区体素。
不能只按总 Dice 挑更激进的清理方式。

之前单例诊断用的是 6 邻接，S3-008 有 36 个组件；本次保守规则用 26 邻接，有 29 个组件。
组件数量因邻接定义不同而变化，不是掩膜发生了变化。S3-008 的 20 张无专家肺区却有预测的切片均清空，
但近主体的小块仍可能保留，这不代表误分已全部解决。

## 产物与查看

- `data/lung_island_cleanup_20261014/screen/evaluation.json`：完整六病例、全部预声明规则与统计。
- `screen/protocol.json`：固定规则、病例划分、受保护输入哈希。
- `screen/<病例>/geometry_decisions.json`：只用预测几何得到的组件与删除决定，不含专家输入。
- `screen/<病例>/predictions_native.npz`：原始、保守清理、最大两个对照的原尺寸掩膜。
- `screen/<病例>/preview.png`：实际轴位/冠状位二值掩膜对比，展示切片按删除面积选取，仅用于可视化。
- `data/lung_island_cleanup_20261014/S3-008/viewer.html`：新独立离线页面，默认原始预测，
  顶部“模型结果”可切换清理后预测。三维网格、三个切面、误差图、Dice 与体积同步切换。
- 同目录 `preview_3d.png`：专家、原始、清理后三维对照；`cleaned_mask.nii.gz` 原尺寸导出。
- `export_report.json`：导出完整性、原页面保持不变、原始掩膜保持不变。

原 `data/lung_3d_viewer_20261013/S3-008/viewer.html` 不覆盖；训练 cache、标注、模型权重不变。
新页面自带 CT/掩膜/网格，无在线资源、无需 Slicer，不实时运行分割或执行板端程序。
清理后是**可选的开发实验层**，不是替换原模型，也尚未做独立 Test/COVID 验证。

## 复现与资源边界

```powershell
.\.venv-lung\Scripts\python.exe python/lung_island_cleanup.py --outdir data/lung_island_cleanup_new/screen --device cuda
.\.venv-lung\Scripts\python.exe python/lung_volume_viewer.py --cleanup-screen data/lung_island_cleanup_new/screen/evaluation.json --source-viewer data/lung_3d_viewer_20261013/S3-008/viewer.html --outdir data/lung_island_cleanup_new/S3-008
.\.venv-lung\Scripts\python.exe -m unittest discover -s python/tests -v
```

输出目录必须为空；若主规则未通过“六例不删除 TP、不降低各例 Dice、删除了一些 FP”，
脚本保留实验记录，但导出器拒绝把清理层接入界面。
不得拿官方 Test/COVID 上的表现反复修改规则再称独立测试。

当前使用 scipy 连通域和 cKDTree，在电脑 CPU 上处理整例。
240×512×512 的 int32 连通域标签仅一份就约 240 MiB，另有预测/专家/主体布尔掩膜、表面点和树；
**不能直接宣称这套实现能放入 PYNQ-Z2 的共享 512 MB DDR，更不是 BRAM 流水线**。
后续板端仍需独立设计更省内存的 PS/DDR 后处理或流式标签方案，并实测资源与延迟。
这一步未改变神经网络参数量，也未生成新的 bitstream。

## 完整性验证

全部 116 项 Python 工程测试通过，包含新增 7 项清理测试与 2 项可选导出/传输测试。
浏览器断网测试通过：三种屏幕同屏布局、三方向独立掩膜显示、色块/轮廓/误差图、
原始/清理后的网格与体素切换、指标同步和原始状态准确恢复。
浏览器例证：S3-008 索引 `[4,234,274]` 的原始误分从 1 变为 0，专家始终为 0、HU 始终为 -295；
实际清理后表面包含 561546 个三角面，与导出网格相符。
记录位于 `data/lung_island_cleanup_20261014/browser_checks/`，测试浏览器已关闭。
