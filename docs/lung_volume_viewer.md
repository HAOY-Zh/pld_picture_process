# 肺区三维与 MPR 切片联动

这是原模型冻结后的**电脑端分割验收/展示模块**，不是新的模型优化或 PL 推理。
用户无需安装 3D Slicer：`viewer.html` 可用近期版 Edge/Chrome 离线打开。
额外的 NIfTI 导出用于之后在成熟软件中交叉复核。

## 当前示例与打开方式

输出目录：`data/lung_3d_viewer_20261013/S3-008/`。

- `viewer.html`：双击或“打开方式 → Edge/Chrome”，可旋转、缩放、观察剖切。
- `preview.png`：专家与模型的静态三维/切片对照。
- `ct_hu.nii.gz`、`expert_mask.nii.gz`、`prediction_mask.nii.gz`：原尺寸 CT 和掩膜。
- `surfaces_native.npz`：原尺寸表面顶点（DICOM LPS，mm）和三角面。
- `report.json`：原模型/数据哈希、掩膜指标、网格规模和电脑端耗时。
- `export_checks.json`：独立导出一致性核对。

HTML 约 79 MB，自带绘图库、CT、掩膜、网格，不调用 CDN，不上传医学图像。
首次加载需解压，浏览器需要一定内存；不要把这解释成板卡程序或板端资源占用。
本例全部输出约 130 MiB，`data/` 已被 Git 忽略，不把 CT 随源码上传。

## 能做什么

桌面端默认四宫格：左上三维、右上轴位、左下冠状位、右下矢状位。
图像按窗口和真实体素间距自适应，不拉伸解剖比例；常用显示模式、窗宽窗位在顶部，
剖切/透明度/定位平面等放在“更多设置／说明”。可点“全屏查看”（Esc 退出）。
宽度不足 900 px 或高度不足 600 px 自动允许滚动；手机窄屏按单列显示，避免强行挤小。

1. 青色专家 / 橙色保留模型，支持单独显示或透明叠加。
2. 轴位、冠状位、矢状位的原 HU 重切片，输入框和滑块同步。
3. 点击切片更新交叉定位；正在操作的切面用紫色平面显示在三维图中。
4. 默认 CT＋半透明肺区色块：青＝仅专家／漏分，橙＝仅模型／多分，绿＝两者重合。
   “更多设置／说明”可调切片色块不透明度（默认 45%，0% 原 CT，100% 实心色块）；
   此设置独立于三维表面不透明度。可切换细轮廓、红 FP / 蓝 FN / 灰 TP 误差图或原 CT，图例同步更新。
   顶部“切片肺区”独立选择“专家＋模型对比 / 仅专家 / 仅模型”，作用于全部三个切片。
   单独显示时青色覆盖完整专家肺区，橙色覆盖完整模型肺区，包括两者原本重合的区域；
   细轮廓模式同样支持单独显示，不影响三维模式或定量指标。
   误差图必须对比两份掩膜，原 CT 不显示掩膜，因此这两种模式暂时禁用肺区选择，切回色块/轮廓恢复之前的选择。
5. 手动窗宽窗位；仅影响显示，不重新运行分割、不改变 HU/标签。
6. 显示整例 Dice、各切面 Dice、分割区域体积及体积差。
7. 观察剖切保留指定索引侧的表面，用于查看内部。切边不补盖，交叉三角面被略去，
   因此有体素级锯齿；定量检查始终依据原掩膜，而不是观察剖切模型。

三维模型没有平滑、填孔、移除孤岛或降采样。内孔和假阳性小块原样保留。
表面是原体素 `.5` 等值面，有限体素分辨率仍有几何近似；漂亮的外壳不证明准确性。
三维不透明外壳可遮住内孔，因此必须保留切片核查。

## 复现与 Slicer（可选）

在电脑项目目录运行，不是在 PYNQ 板上运行：

```powershell
.\.venv-lung\Scripts\python.exe -m pip install -r python/requirements-lung.txt
.\.venv-lung\Scripts\python.exe python/lung_volume_viewer.py --case LCTSC-Train-S3-008 --slice 72 --outdir data/lung_3d_viewer_new/S3-008 --device cuda
.\.venv-lung\Scripts\python.exe -m unittest discover -s python/tests -v
```

输出目录必须为空。脚本只推理冻结原模型，不提供训练、阈值调优或标签清理选项。
PyTorch 仍按训练说明安装；3D Slicer 不是依赖。

只更新已有页面排版，不重新推理、不读取源 CT：

```powershell
.\.venv-lung\Scripts\python.exe python/lung_volume_viewer.py --refresh-html data/lung_3d_viewer_20261013/S3-008/viewer.html
```

更新前后嵌入的 HU、两份掩膜、网格、指标和坐标数据逐字节一致。
`viewer.layout.json` 记录新的 HTML 哈希；`report.json` / `export_checks.json` 保留初次导出的历史记录，
其中旧 HTML/模板哈希不代表更新后的文件。其他 NIfTI、NPZ 和静态预览不重写。

如之后使用 Slicer，将 CT 作为图像加载、两份掩膜作为 Segmentation 加载，点击 `Show 3D`；
对照时关闭表面转换平滑，保留原标注。参见
[Slicer 官方分割/三维文档](https://slicer.readthedocs.io/en/5.10/user_guide/modules/segmentations.html)。
