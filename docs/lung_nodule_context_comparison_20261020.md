# 肺结节上下文对照：最终结果

**近远5层、7层均已完成30轮训练、全部47例开发校准评价、独立审计和4例独立测速。按用户要求，9层未启动。**

“每套/每卷CT”指一个完整三维CT序列，包含该序列的全部切片。新的56例、90个参考结节测试集仍封存。

## 如何判断这次改进

7层在低误报档有小幅收益：平均误报上限0.5个/套时，检出从40/56（71.4%）升至43/56（76.8%）；4误报档仍为50/56（89.3%），8误报档从53降至52。综合CPM从0.79337升到0.80867。可保留为低误报备选，尚不足以认定全面优于原5层。

近远5层在4误报档新增命中2个、丢失1个，净增1个；综合CPM下降，不能仅凭该档成绩替换原版。7层4误报档与原版命中的50个参考结节完全相同。

本次验证了更多上下文在哪些档位有用以及代价多少，属于有对照的小改进。单纯增加输入层数的创新性有限。下一步宜固定模型和阈值，再用封存56例验证收益稳定性，之后再判断是否值得上板；本轮未进行这些后续步骤。

## 独立测速

旧评价进程内计时出现同结构约五倍差距，已标为被替代，不用于速度结论。以下是全部训练和评价CUDA进程退出后，充分预热、轮换顺序、CUDA事件计时的新测量。四例同结构对照耗时比0.988～1.009，控制检查全部通过。
