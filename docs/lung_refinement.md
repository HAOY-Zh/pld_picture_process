# 针对肺内错误排除的受控微调

> 清理记录（2026-10-15）：本方案未采用，详细 `evaluation.json` 和 `history.json` 已按用户要求删除。本文的实验结论与结果表保留；下文相关报告路径仅为历史记录，不表示文件仍存在。配置、元数据、源码及对比图未删除。

2026-10-12 已完成第一轮候选微调，**未通过目标验收，不替换原模型**。
这是电脑端开发验证，不是新盲测、医学诊断验证或 PL 推理。
原有冻结评价源码、原模型、训练/验证人工标签均未改动。

## 本次只改变训练目标权重

- 从原 2D U-Net 第 12 轮 `early_stop_run/best.pt` 初始化。
- 结构仍为 base=8、单层 256×256 输入、122,321 参数；推理仍为原尺寸概率双线性恢复后阈值 0.5。
- 原 18 个训练病例共 3002 层、6 个开发验证病例共 1120 层，保留空肺切片。
- 对人工标签为肺且模型输入对应 HU ≥ -400 的像素，BCE 损失权重为 2；
  其他像素为 1。加权 BCE 除以权重总和，再加原 soft Dice。
  HU 条件只控制训练难例强调，不生成标签，不用于推理决定肺/非肺。
- 新 Adam，学习率 0.0001，batch=8，4 轮；沿用同步左右翻转。
  这是从基线初始化的微调，不恢复旧优化器或旧早停计数。
- 不读取 Test 病例或 COVID 外部病例选择模型，不做孔洞填充/开闭运算。

验收前固定：平均病例 Dice 降幅不超过 0.001；输入较亮肺区 FN 至少减少 10%；
总 FN 不增加；总 FP 增幅不超过 5%；空层 FP 像素增幅不超过 10%、
空层出现前景的层数不增加；小肺区 Dice 降幅不超过 0.01。
这些是探索性工程门槛，不是医学设备验收标准。

本次“较亮肺区”指标先按网络的 256×256 输入亮度取区域，再最近邻映射到原尺寸，
与未修改的原尺寸人工肺掩膜相交。它不是感染标注，也不同于此前按原始 HU 统计的亮度分组。

## 实际结果

4 轮全部未通过验收；第 4 轮整体 Dice 最高，因此仅保存为拒绝采用的探索候选：

| 六病例开发验证指标 | 原模型 | 候选第 4 轮 |
| --- | ---: | ---: |
| 平均病例 Dice | 0.966576 | 0.966796 |
| 输入较亮肺区漏分像素 | 214,447 | 241,139 |
| 全部肺区漏分像素 | 260,190 | 265,685 |
| 肺外多分像素 | 272,856 | 250,061 |
| 小肺区逐切片 Dice | 0.462901 | 0.436847 |
| 空参考层出现前景 | 40 / 516 | 54 / 516 |
| 空参考层多分像素 | 11,353 | 32,996 |

目标亮区 FN 增加约 12.45%。整体 Dice 略升主要不能代表目标错误改善，
空层和小肺区表现变差，决定为 `do_not_replace_original`。
不能据此断言所有损失加权方法都无效，也不能将变化单独归因于加权：
本次没有同时训练一个相同初始化、相同学习率的未加权续训对照。

本次训练代码与缓存、基线权重、数据清单等共 51 个输入文件 SHA256 在运行后复核未变。
63 项完整工程测试通过，新增测试覆盖正标签独占增权、权重 1 与原损失一致、
拒绝误分膨胀和最小真实训练的基线/标签保护。工程测试不等于精度达标。

## 第二轮：局部亮度增强与同条件续训对照

2026-10-12 两组各 4 轮已经完成，均未通过验收，不替换原模型。
复用 `python/lung_refine.py`，不另建一套训练/推理脚本。

- 两组都从原第 12 轮权重初始化，使用原 BCE + Dice（`--weight 1`）、新 Adam、
  LR=0.0001、batch=8、4 轮、seed=20261012、18 TRAIN / 6 VALIDATION。
- 沿用同一个采样顺序和同步左右翻转；增强使用独立随机数流，不改变翻转随机数。
  CUDA 未强制逐位确定性，属于单随机种子的探索，不是重复试验的显著性结论。
- 对照组 `--augmentation none`；增强组 `--augmentation local-brightness`。
- 每层概率 0.5 生成一个平滑的亮度增量斑块，峰值随机 150～450 HU，
  半径 12～32 个网络输入像素，边缘连续衰减；归一化输入裁剪到 [0,1]。
  这些半径是 256 输入像素，不是固定毫米，也不声称模拟真实疾病。
- 只允许改变训练人工肺掩膜的受保护内部：9×9 全为正标签的位置，进一步平滑衰减。
  背景、人工边界附近、小于该内部条件的薄肺区及空肺层保持不变；人工标签始终不变。
  这里的标签约束仅用于生成训练样本，不是模型推理算法或掩膜后处理。
- 验证和推理不增强、不用人工标签生成输入；网络参数量、结构和推理阈值均不变。
  这是标签条件合成增强，可能引入训练分布偏差，须用未增强的验证病例检查。
- 沿用前述预声明验收门槛；不读原 Test 或 COVID 病例选新模型。
  不自动覆盖原权重，不转换新 INT8，不修改 FPGA 比特流。

```powershell
.\.venv-lung\Scripts\python.exe python/lung_refine.py --outdir data/lung_refine_20261012/local_brightness --epochs 4 --weight 1 --augmentation local-brightness --threshold-hu -400 --lr 0.0001 --seed 20261012 --device cuda
.\.venv-lung\Scripts\python.exe python/lung_refine.py --outdir data/lung_refine_20261012/continuation_control --epochs 4 --weight 1 --augmentation none --threshold-hu -400 --lr 0.0001 --seed 20261012 --device cuda
```

每组独立保存协议、逐轮指标、实际增强层数/像素数、原尺寸预测、两张固定验证病例对照图。
本次完整工程测试 65 项通过，另覆盖增强的独立随机数、背景/边界/标签保护、
输入裁剪、薄/空掩膜、非法参数和最小真实训练接入。
第一轮权重 2 实验的历史文件保持原样；历史协议和权重保存的是当时源码哈希。

### 第二轮实际结果

两组在没有合格候选的情况下，均保留第 3 轮为各自最高平均病例 Dice 的探索结果；
这些并不是通过验收的部署模型。选择规则沿用既有协议，不事后改为按亮区指标挑轮数。

| 六病例开发验证指标 | 原模型 | 无增强续训（第 3 轮） | 局部亮度增强（第 3 轮） |
| --- | ---: | ---: | ---: |
| 平均病例 Dice | 0.966576 | 0.966380 | 0.966818 |
| 输入较亮肺区漏分像素 | 214,447 | 273,938 | 256,903 |
| 全部肺区漏分像素 | 260,190 | 303,622 | 293,289 |
| 肺外多分像素 | 272,856 | 213,736 | 220,703 |
| 小肺区逐切片 Dice | 0.462901 | 0.426767 | 0.425407 |
| 空参考层出现前景 | 40 / 516 | 39 / 516 | 21 / 516 |
| 空参考层多分像素 | 11,353 | 30,551 | 20,501 |

增强比所选同条件对照的亮区 FN 少约 6.22%，但仍比原模型多 19.80%；全部 FN 比原模型多 12.72%。
不能据整体 Dice 略升说内部漏分已经修复，也不能把与普通续训的差别当成泛化已改善。
这仅是同种子、同预算的开发验证对照，不是多次重复试验或新独立测试；
连续使用同一验证集选开发方法也意味着它不是新的盲测。

四轮增强实际改变 800、803、802、776 个训练切片的局部输入，分别改变
437,948、432,179、437,051、406,690 个输入像素；对照组全部为零。
两组 51 个受保护输入文件均在实验结束复核 SHA256 未变，原初始化权重与人工标签保留。
两个输出目录均没有 `accepted_candidate.pt`；原尺寸验证预测已保存，没有使用原 Test/COVID 病例。

增强组两张对照图位于 `data/lung_refine_20261012/local_brightness/`：

- `comparison_LCTSC-Train-S2-006_slice_054.png`
- `comparison_LCTSC-Train-S3-008_slice_079.png`

青色人工、黄色原模型、绿色本次增强候选；最右图灰色正确、红色多分、蓝色漏分。
无增强组在 `data/lung_refine_20261012/continuation_control/` 保存同名切片对照图，
其绿色代表无增强续训候选，不代表增强模型。

结论：局部亮度增强已经实现、测试并完成受控实验，但这组设置未达到修复目标。
没有继续自动搜索更多亮度参数，没有增大网络或承诺 FPGA 已部署；
后续需要重新评估困难样本的训练覆盖和训练目标，不能仅靠更多续训认定有效。
