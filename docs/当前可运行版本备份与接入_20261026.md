# 当前可运行版本备份与接入（2026-10-26）

本分支 `codex/ct-studio-current-20261026` 保存本次新优化开始前的运行版本：统一网页、100 MHz LDCT、原 U-Net 肺分割、2.5D 结节检测、冻结跨层评分、MPR/三维候选联动、ROI 和基础处理。没有加入正在规划的更强三维清理或“各部分再快 10%”改动。

仅用于工程教学与算法演示，不作为临床诊断依据。

## 新电脑安装和打开网页

```powershell
git clone --branch codex/ct-studio-current-20261026 --single-branch https://github.com/HAOY-Zh/pld_picture_process.git
cd pld_picture_process
py -3.11 -m venv .venv-web
.\.venv-web\Scripts\python.exe -m pip install -r python/requirements-current.txt
.\.venv-web\Scripts\python.exe -B -X utf8 python/ct_studio_current_release.py install
.\.venv-web\Scripts\python.exe -B -X utf8 python/ct_studio_current_release.py verify
```

安装生成 `data/ct_studio_current_20261026`。其中 `ct_studio` 是完整板端目录；电脑配置、冻结评分参数和本机生成的密钥在其上级。普通 Git 下载包含配套 ZIP，无须找作者电脑上的 data 目录。

**请使用 Python 3.11 和 NumPy 1.26.4。** 便携 EXE 原环境的 NumPy 2.4.6 曾造成采样舍入差异，当前启动环境固定为已核验的 1.26.4。不要直接安装旧的 `requirements-pc-verified.txt` 代替本页命令。

板端尚未准备时，可先打开不连接 FPGA 的浏览页面：

```powershell
.\.venv-web\Scripts\python.exe -B -X utf8 python/ct_workspace_web.py --desktop --port 8099
```

此模式可导入和浏览 CT、运行基础电脑参考，不会执行 FPGA 神经推理。

板端匹配并完成启动自检后，启动实际 FPGA 页面：

```powershell
.\start_ct_studio_current.cmd
```

地址为 `http://127.0.0.1:8099/`。不要用带 `**` 的地址。若 8099 已有其他版本，先保留其工作结果，或显式改用其他端口。

## 配对板端和开机服务

把本次安装产生的整个 `ct_studio` 目录复制到板子新目录，例如 `/home/xilinx/ct_test/ct_studio_current_20261026`。电脑与板子必须来自同一次安装；重新安装会生成另一组密钥和清单，不能拿新的电脑配置直接连接旧板端服务。

原运行服务完全空闲并正常退出后，板端终端可前台启动：

```bash
cd /home/xilinx/ct_test/ct_studio_current_20261026
sudo /usr/local/share/pynq-venv/bin/python3 -B -u ct_dual_io_owner.py --folder "$PWD" --expected-manifest "$(sha256sum platform_manifest.json | cut -d ' ' -f1)" --port 8766
```

首次真实自检可能需要数分钟；应看到 `DUAL EXACT I/O READY` 后再连接。systemd 的 `active (running)` 只表示进程已运行，不能替代硬件就绪。

需要自启动时，把仓库中的 `python/install_ct_studio_current_boot.py` 复制到板子，再执行：

```bash
sudo /usr/local/share/pynq-venv/bin/python3 install_ct_studio_current_boot.py --folder /home/xilinx/ct_test/ct_studio_current_20261026 --enable-next-boot
```

该命令只安装开机配置，不停止或启动当前硬件。重启前核对并禁用旧所有者的开机启动，尤其 `ct-studio-shared-batch.service`，以及仍依赖旧所有者的 `ct-studio-ps-web.service`。不要运行旧的 `install_ct_studio_boot.py` 来安装这个新版所有者。

作者板子本次已经实际禁用旧 shared-batch、启用 dual-exact-r2，并验证网页连接成功；尚未断电重启验证。本分支不能保证另一块板子自动继承作者的 systemd 设置。

- 结节输出使用冻结跨层评分及固定阈值 0.6418673229668569；没有回退成旧网页的原始 CNN 全候选显示。
- 分割、结节、ROI 都明确绑定当前分析来源。选择增强 CT 后不会再等同于原始 CT 的输入或输出。

- 源码版网页和队友 EXE 外壳是两层。本分支提供当前实际网页、Python/C++、Verilog 与运行资产；未上传含本机密钥的 250 MB EXE 配套私有 ZIP。桌面打包说明另见 `桌面exe接入最新版_20261026.md`。
