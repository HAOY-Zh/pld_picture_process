## 本轮具体改动

### 原生 XY 采样

原实现用 `ndimage.map_coordinates(order=1, mode='constant', cval=-1000)` 生成每个原生 CT 平面的 XY 插值。新 C++ 实现只针对这一固定契约，预先计算每行/列的索引和权重，再用最多两个 CPU 线程处理原生平面。

保持双精度权重、四个邻居的相同乘加顺序、越界整点返回 −1000、最终一次 float32 转换。使用 `-ffp-contract=off -fno-fast-math`，不改为最近邻、不使用近似权重。原 NumPy 的 Z 层混合、`rint`、裁剪与 INT16 转换继续原样执行。

本轮只做每次检测平面内部的共享采样，没有实现跨检测层缓存；不存在预热后跳过采样来制造完整平面提速。

### 解码数据与循环精简

原来会为每个 tile 分配完整 5×64×64 输出，填入解码所需区域后逐 tile 做峰值、位置和肺掩膜检查。新路径只复制原来必需的 5×34×34 区域，并沿 tile 维度用大小为 1 的滤波窗口批量计算，各 tile 不互相影响。

保留相同的 3×3 邻域、峰值相等条件、核心边界和 tile/y/x 顺序；向全局坐标还原时恢复原偏移。向量化坐标和肺掩膜检查，显式复现当前 NumPy 版本的标量类型提升，避免 NumPy 1.x/2.x 导致 Z 中心舍入差异。最终 `consolidate` 和空间 NMS 原样保留。

直径回归使用既有 INT8 通道的全部 256 个值建立精确参数表，每项调用原标量公式生成。查表前重建并确认输入值确实属于该通道编码；一般浮点输入保留原标量公式回退。不是近似 exp、修改阈值或减少候选。

## 验证范围

- 7 项数值/数据检查：全 HU 范围随机值、整数/半整数坐标、边界外与单轴图像、只读带步长输入、Z 混合和舍入、不同上下文位置、平顶高分峰值、搜索掩膜、所有直径编码及通用回退、完整/紧凑解码一致性。
- 1 项驱动流程检查：原生采样实际执行，CNN/PL 使用显式测试替身来检查四组调度、输出留存、均值计算和独立验收拒收篡改；不把它当作 FPGA 数值仿真。
- 真实 448×448 冻结病例运行实际 C++ INT8 CNN：原/新五层输入、完整检测头、合并前中心/分数/直径及 69 个最终平面候选全部逐值一致。证据在构建目录 `local_final/verification.json` 与 `outputs.npz`。

桌面耗时只用于定位与数值对照，机器状态会影响数字，不能用它预测 PYNQ 加速比例。新路径的 ARM 实际速度、所用 NumPy/SciPy 和编译器下的等价性由板端脚本再次验证。

这轮保持网络结构、权重、INT8 量化、5 层上下文、空间步长、候选阈值和 NMS 不变。没有重新训练或把同一批数据重跑后声称是新的独立检出率评价。

## 如何读新的性能结果

- `sample_ms`：本次在线生成五层上下文，包含原生工作。
- `input_pack_ms`：原生 HU 量化与 stride-2 打包。
- `network_ms`：常驻网络调用。PL 还包含输入同步、控制、保护区检查和结果读回；ARM 是原生 CNN 调用。不称为裸 MAC 时间。
- `extract_ms`、`decode_regression_ms`、`plane_merge_ms`：解码输入组织、峰值/回归/肺掩膜筛选、平面 NMS。
- `hardware_active_ms`：PL 命令计数，包含总线等待，是网络调用的一部分，不能另外相加。
- `slice_sampling_to_candidates_ms`：完整检测平面，包括上述在线处理；不含原先肺分割、病例传输、整卷跨层评分、bit/模型构造及仅供核对的额外比较。

`same_optimized_arm_vs_pl` 是新前后处理下公平的完整平面对比。`resident_call_arm_vs_pl` 是相应网络调用对比；不能把 ARM 完整流程除以 PL 硬件计数作为加速比。

无论结果如何，ARM 和 PL 都同时获得共用前后处理优化，以实际使用时间评价收益。
