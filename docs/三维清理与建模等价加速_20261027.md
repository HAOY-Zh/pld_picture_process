# 三维清理与建模等价加速（2026-10-27）

两例的清理掩膜逐体素相同，连通域大小、保留/删除决定和距离记录完全相同；两个网格的原生顶点、毫米坐标和三角面数组逐元素相同。另通过 28 组空掩膜、边界贴合、255编码和随机网格对照及 53 项既有回归检查。没有新训练、没有新临床精度评估。
