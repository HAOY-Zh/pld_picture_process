# PYNQ-Z2 医学图像处理项目

基于 PYNQ-Z2 / Zynq-7000 的医学图像处理工程，包含 Verilog 图像处理模块、
AXI DMA 数据通路、板端交互程序，以及肺部 CT 分割的离线开发代码。

**仅用于工程教学与算法演示，不作为临床诊断依据。**

## 队友电脑快速启动网页

需要Python 3.11。Windows PowerShell在项目根目录执行：

```powershell
py -3.11 -m venv .venv-web
.\.venv-web\Scripts\python.exe -m pip install -r python/requirements-web.txt
.\.venv-web\Scripts\python.exe python/ct_workspace_web.py --desktop
```

浏览器打开 **http://127.0.0.1:8090/**。此模式不需要PYNQ板、PyTorch、模型文件或服务令牌，可以加载本机CT、浏览三个切面并运行基础处理电脑参考；不会生成神经分割、FPGA回执或肺三维结果。基础、分割与三维、性能三个页面均保留，真实推理按钮在连接实际板端前不可用。

没有CT时可生成不含患者数据的合成教学样例：

```powershell
.\.venv-web\Scripts\python.exe python/create_demo_ct.py
```

将命令输出的路径粘贴到网页，勾选“确认NIfTI / NPZ为CT HU，空间单位mm”，取消加载专家标注后加载。样例只用于检查显示与基础处理，不能用于医学效果评价。

若直接运行网页脚本，且本机没有默认板端配置，也会明确进入电脑浏览模式。实际FPGA功能使用匹配运行包和私有凭据，通过 `--config <主机配置.json>` 启动；显式配置错误直接报错，不改用电脑模拟推理。详见 [电脑启动与板卡接入](docs/网页电脑启动与板卡接入.md)。

## 开发环境与数据通路

- 开发板：PYNQ-Z2，器件 `xc7z020clg400-1`。
- 当前 Vivado 工程版本：2022.2。
- 板端：PYNQ / Python / Jupyter。
- 离线开发：Python 3.11；本机模型环境使用 PyTorch 2.8.0 + CUDA 12.6。

基础处理的数据流为 DDR → DMA MM2S → PL 图像处理模块 → DMA S2MM → DDR。
PS 负责数据组织、参数配置、传输控制和显示；对应基础处理的核心运算由 PL 执行。
模型训练与离线参考在电脑CPU/GPU运行；在线肺分割前向已有真实FPGA实现，电脑继续负责原有预后处理与三维显示。
