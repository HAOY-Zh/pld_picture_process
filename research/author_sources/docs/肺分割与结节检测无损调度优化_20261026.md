# 肺分割与结节检测无损调度优化（2026-10-26）

**已完成实板验收并接入正式网页 8099，默认启动器和板端开机服务均已切到修复版。**

本轮目标：保持现有 INT8 模型、权重、bit、100 MHz 时钟、搜索范围、采样位置、量化舍入、后处理和评分阈值，优化执行调度、板端数据排列、缓存同步及通信。这里的“无损”指相对于当前整数版本逐值一致，不表示原模型没有误检或漏检，也不表示 INT8 与 FP32 完全一致。

## 改动与边界

1. 肺分割用原生 C++ 将原单通道编码直接写入 HWC8 CMA，填充通道仍为 0，不生成中间重排数组。
2. 两个模型仍执行全部原有 PL 命令；保留超时、完成计数、输出字数、全部缓冲区哨兵检查及故障保留机制。仅把结尾的缓存失效缩到实际读取的保护区与最终输出；观察中间节点时仍同步完整节点。
3. 肺分割用有长度上限、完整哈希及版本校验的二进制返回，复用连接，省去 Base64 封装。
4. 电脑用单个后处理线程整理上一张分割结果，同时串行提交下一张推理。还原分辨率、人体约束、专家评价、保存掩膜及三维清理规则不变，最多只有一个后处理任务在途；异常和取消都会等待其结束。
5. 结节检测按五个原始量化平面的内容哈希缓存，已存在的平面不重复传输。板端重建后重新校验完整五平面输入哈希，随后仍运行完整网络。不删采样平面，不缩搜索范围，不减候选。
6. 缓存最多 10 个平面、8 MiB 普通 CPU 内存，不新增 CMA 工作区，不增加 FPGA 缓存电路。缓存缺失在提交硬件之前拒绝，不自动重试推理。
7. 发送前主动重建空闲超过 3 秒的连接，解决服务端 10 秒空闲关闭后客户端复用旧连接的问题。失败的推理请求不会自动重放。

肺分割电脑后处理包括：256×256 输出恢复到原切片尺寸、人体范围约束、整卷三维孤立区域清理、体积统计和三维表面生成。结节电脑后处理包括：检测头解码、候选合并与冻结跨层评分。上述计算没有被冒称为 PL 运算。

## 本地与实板验收

本地 8 项测试覆盖原生布局、保护区、调度 AST 对照、后处理函数体对照、缓存重建/上限/哈希错误、压缩流边界、双接口二进制返回、空闲重连与硬件故障不重试。

实板验收使用同一 351 张切片病例。该病例没有专家标注，因此本轮用旧版完整输出作为等价性基准，不新增 Dice 或检出率结论。需逐张比较全部输入编码与完整输出，比较 raw/body/cleaned 三维掩膜和肺体积；结节逐一比较全部完整检测头、原始/评分候选及最终结果。

旧版完整肺分割基准已完成：221.139 秒（含后处理、保存与三维生成），板端网络平均 427.935 ms/张，PL 活动平均 348.488 ms/张，请求往返平均 485.650 ms/张。

肺分割 351 张输入编码、完整输出及 raw/body/cleaned 三维掩膜全部逐值一致，肺体积均为 3,626.810913 mL。
结节 202 个完整检测头哈希、5,324 个合并后评分候选及最终 10 个候选全部严格相同。这里的候选数不能当作真结节数或误报数。

结节新旧两次整例中，电脑搜索、采样及评分等阶段的计时也发生变化；新整例结果只有 2.18% 的小幅差异，因此不据此宣称获得稳定的整例大幅加速。
另在同一进程、同一板端运行时中，用 12 个连续真实平面交替先后顺序比较旧 V2 传输和新 V3 缓存传输（首个平面热身排除），所有完整输出均与原记录相同。平均往返 **396.408 → 330.843 ms**，减少 **16.54%**，约 **1.198 倍**。这个数是请求往返，不能替代整例或纯 PL 加速比。

缓存范围同步实验本身没有测出收益：肺分割结尾检查平均 7.702 → 9.892 ms，结节累计 901.381 → 1,169.826 ms。完整校验仍保留，不能把这项调整列作已证实的提速点；本轮证实的主要收益是输入排列、流水调度和减少重复传输。

## 资源与功耗口径

同一 bit 的资源不变：17,865 LUT、20,063 FF、80 DSP、31.5 BRAM tile。它是肺分割与结节复用引擎的资源，不是 LDCT、基础处理、ROI 等所有 Overlay 的相加总量。

本例内容缓存最高使用 1,720,320 B（约 1.64 MiB）普通 CPU 内存，换取传输量降低；全部 202 个平面的 CMA 工作区大小与旧版相同。不能将 CPU 缓存当作新增 BRAM，也不能宣称本轮减少了 FPGA 物理资源。

本轮没有重新综合，也没有实际测量供电功率，不能声称物理资源或功耗已经下降。减少通信和冗余 CPU 内存访问、缩短任务时间有节能潜力；能耗是否降低及降低多少仍需同一供电边界下实测。任务时长不能直接当作功率。
